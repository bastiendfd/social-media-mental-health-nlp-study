# Security Policy

## Scope

Report vulnerabilities in repository code, CI configuration, dependency handling, or violations of the synthetic-only boundary.

## Reporting

Please use GitHub's private vulnerability reporting for this repository. Do not include sensitive information, real social-media content, account identifiers, secrets, or personal data in an issue or report.

## Data and model boundary

No real social-media data or model artifact is distributed. The project is not a depression detector, is not diagnostic, and must not be used for clinical, employment, insurance, or individual-risk decisions. Reports that identify accidental inclusion of prohibited material are especially welcome.
